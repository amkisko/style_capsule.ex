# 0.9.0 engineering audit fixes

## Participants

Andrei Makarov

## Decisions

Cut 0.9.0 for the public Registry rename and the CSS and HTML contract fixes found in the audit.

Keep StyleCapsule.Registry as a deprecated delegate for one release.

Do not add a telemetry dependency. Wrap remaining execute calls in Instrumentation.safe_execute.

Leave ComponentRegistry unstarted. Leave Mix verify as a writability check. Leave file cache as write-through.

## Effects

CssProcessor.patch_selectors skips @ selectors and from/to/percent keyframe stops. Host translations run before the capsule prefix so :host(.active), :host-context(.dark), and :host .content each get one prefix.

validate_css! rejects </style> case-insensitively and rejects a non-binary CSS body.

Wrapper.validate_tag! is shared by wrap/3 and Component.capsule/1.

FileWriter.write/3 calls Id.validate! and contained_path! for both the output and fallback directories.

Phoenix.render_stylesheet_links escapes href. convert_file_path_to_url splits on priv/static/.

capsule/1 try is limited to StyleCapsule.capsule_id/1. register_inline no longer rescues all errors.

ETS table create in Cache and Instrumentation rescues ArgumentError for the create race.

Id.generate/2 raises when prefix plus hash exceeds 32 characters.

CompileRegistry writes style_capsule_registry.etf.

mix.exs version is 0.9.0. README pin is ~> 0.9.0 with Phoenix ~> 1.8 and LiveView ~> 1.1.
